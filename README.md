# Crasants-Portfolio
Art portfolio for crasants. Anyone can view the gallery; uploading and deleting require the admin password.

## Run
```
npm install
npm run build
ADMIN_PASSWORD=your-password npm run server   # http://localhost:3001
```
For development: run the server as above, then `npm run dev` in another terminal.
```
git checkout copilot/basic-webpage-for-artwork
git pull
```
